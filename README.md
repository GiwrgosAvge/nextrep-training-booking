# NextRep — Κρατήσεις προπονήσεων

Εφαρμογή κρατήσεων για προσωπικό προπονητή, με ξεχωριστή σύνδεση για προπονητή και ασκούμενους. Το UI είναι στα ελληνικά και τα δικαιώματα ελέγχονται πάντα στον server.

## Τεχνολογίες

- **Client:** React, TypeScript, Vite και React Router.
- **Server:** Node.js, Express και TypeScript.
- **Βάση:** SQLite μέσω `better-sqlite3`.
- **Authentication:** συνεδρίες server-side και cookie `httpOnly`.
- **Κωδικοί:** αποθηκεύονται ως bcrypt hashes.
- **AI:** υπάρχει προαιρετική ενσωμάτωση Anthropic, απενεργοποιημένη από προεπιλογή για να μη γίνονται χρεώσιμα αιτήματα.

## Προαπαιτούμενα

- Node.js 22.12.0 ή νεότερο.
- npm.

## Ρύθμιση

1. Από τη ρίζα του project εγκατάστησε τα dependencies:

   ```powershell
   cd server
   npm.cmd install
   cd ..\client
   npm.cmd install
   ```

2. Αντίγραψε το `server/.env.example` ως `server/.env` και συμπλήρωσε τοπικά τις δικές σου τιμές. Μην ανεβάσεις το `.env` στο Git και μην μοιραστείς τις τιμές του:

   ```powershell
   Copy-Item server\.env.example server\.env
   ```

   Όρισε ένα τυχαίο `SESSION_SECRET` με τουλάχιστον 32 χαρακτήρες, `TRAINER_USERNAME` με 3–32 λατινικούς χαρακτήρες, ψηφία ή `._-`, και `TRAINER_PASSWORD` με τουλάχιστον 12 χαρακτήρες. Το `SESSION_SECRET` και τυχόν κλειδιά API μένουν μόνο στον server. Το αρχείο `.env` εξαιρείται από το `.gitignore`. Ο πρώτος λογαριασμός προπονητή δημιουργείται στην εκκίνηση, εφόσον δεν υπάρχει ήδη.

3. Εκκίνησε τον server σε ένα terminal:

   ```powershell
   cd server
   npm.cmd run dev
   ```

4. Εκκίνησε τον client σε δεύτερο terminal:

   ```powershell
   cd client
   npm.cmd run dev
   ```

5. Άνοιξε το `http://localhost:5173`.

Αν το σύστημα PowerShell μπλοκάρει το `npm`, χρησιμοποίησε `npm.cmd` όπως στα παραπάνω παραδείγματα.

### Γρήγορη δοκιμή με demo δεδομένα

Για να δεις αμέσως γεμάτη εφαρμογή, μετά το βήμα 2 και **πριν** την πρώτη εκκίνηση του server τρέξε:


Δημιουργούνται ώρες για τις επόμενες δύο εβδομάδες, ραντεβού (μελλοντικά και παλιά) και οι παρακάτω λογαριασμοί. Οι κωδικοί είναι δημόσιοι και προορίζονται **μόνο για τοπική δοκιμή**:

| Ρόλος | Όνομα χρήστη | Κωδικός |

| Προπονητής | `demo.trainer` | `NextRep-Demo-2026` |
| Ασκούμενοι | `maria.demo`, `nikos.demo`, `eleni.demo` | `NextRep-Client-2026` |

Όταν υπάρχει demo προπονητής, τα `TRAINER_USERNAME`/`TRAINER_PASSWORD` του `.env` αγνοούνται. Το script αρνείται να τρέξει σε βάση που έχει ήδη λογαριασμούς, ώστε να μην αλλοιώσει πραγματικά δεδομένα, και δεν τρέχει με `NODE_ENV=production`. ### Δοκιμή σε κινητό στο ίδιο Wi-Fi

Στο VS Code επίλεξε **Terminal → Run Task → Εκκίνηση server και εφαρμογής**. Η εργασία ξεκινά το API μόνο στον υπολογιστή και τον Vite client στο τοπικό δίκτυο και εμφανίζει τη διεύθυνση που πρέπει να ανοίξεις στο κινητό. Το κινητό και ο υπολογιστής πρέπει να είναι συνδεδεμένα στο ίδιο Wi-Fi. Αν τα Windows εμφανίσουν ειδοποίηση firewall, επίτρεψε πρόσβαση μόνο σε ιδιωτικά δίκτυα.

Η διεύθυνση LAN προορίζεται για προσωρινή δοκιμή μέσα στο τοπικό δίκτυο. Δεν είναι HTTPS, επομένως δεν ενεργοποιεί την εγκατάσταση PWA στο κινητό.

## Εγκατάσταση στο κινητό (PWA)

Η εφαρμογή μπορεί να προστεθεί στην αρχική οθόνη και να ανοίγει σε αυτόνομο παράθυρο:

- **iPhone:** άνοιξε την εφαρμογή στο Safari, πάτησε «Κοινή χρήση» και μετά «Προσθήκη στην οθόνη Αφετηρίας». Ενεργοποίησε το «Άνοιγμα ως εφαρμογή web», αν εμφανίζεται.
- **Android:** άνοιξε την εφαρμογή στο Chrome και επίλεξε «Εγκατάσταση εφαρμογής» ή «Προσθήκη στην αρχική οθόνη».

Για εγκατάσταση σε πραγματικό κινητό, η εφαρμογή πρέπει να φιλοξενείται μέσω HTTPS. Το `http://localhost` θεωρείται ασφαλές για τοπικές δοκιμές στον ίδιο υπολογιστή, αλλά μια διεύθυνση LAN όπως `http://192.168.x.x` δεν ενεργοποιεί το service worker στο iPhone. Στο development server η εγγραφή του service worker είναι απενεργοποιημένη· δοκίμασε PWA από production build σε HTTPS.

Το manifest και τα εικονίδια ορίζουν την εμφάνιση της εφαρμογής και της οθόνης εκκίνησης. Το service worker αποθηκεύει μόνο το κέλυφος και τα στατικά αρχεία της εφαρμογής. Δεν αποθηκεύει αιτήματα `/api`, στοιχεία σύνδεσης ή ραντεβού· για να δεις ή να αλλάξεις προσωπικά δεδομένα χρειάζεται σύνδεση στο διαδίκτυο.

## Χρήση σε κινητό

- Η εφαρμογή εμφανίζεται ως κεντραρισμένη στήλη σε μεγάλες οθόνες και χρησιμοποιεί κάτω πλοήγηση για τις βασικές ενότητες.
- Άλλαξε ανά πάσα στιγμή μεταξύ ανοιχτού και σκούρου θέματος από το κουμπί με τον ήλιο/φεγγάρι. Η επιλογή αποθηκεύεται στη συσκευή· αν δεν έχεις επιλέξει θέμα, ακολουθεί τη ρύθμιση εμφάνισης της συσκευής.
- Στην καρτέλα «Σήμερα» του προπονητή, πάτησε τα σύνολα «επόμενα ραντεβού» ή «ελεύθερες ώρες» για να μεταβείς στην αντίστοιχη καρτέλα.
- Οι επιβεβαιώσεις και οι επιλογές ανοίγουν σε κάτω φύλλα. Σύρε ένα ραντεβού ή μια ώρα προς τα αριστερά για να ανοίξει η σχετική ενέργεια· η διαγραφή ή ακύρωση απαιτεί πάντα επιβεβαίωση και υπάρχει και ορατό κουμπί.
- Στην καρτέλα «Ραντεβού», τράβηξε τη λίστα προς τα κάτω για ανανέωση ή χρησιμοποίησε το κουμπί «Ανανέωση».

## Ρόλοι και λειτουργίες

### Προπονητής

- Συνδέεται με τα στοιχεία `TRAINER_USERNAME` και `TRAINER_PASSWORD`.
- Αν ξεχάσεις τον κωδικό τοπικά, από τον φάκελο `server` τρέξε `npm run reset:trainer-password`. Το εργαλείο ζητά επιβεβαίωση username και νέο κωδικό χωρίς να εμφανίζει τον κωδικό στην οθόνη, και ακυρώνει τις ενεργές συνεδρίες του προπονητή.
- Βλέπει το πρόγραμμα, όλες τις κρατήσεις και τα ονόματα των ασκούμενων.
- Προσθέτει ή διαγράφει ώρες και μπορεί να ακυρώσει ραντεβού ή να αλλάξει την ώρα τους.
- Δημιουργεί, απενεργοποιεί, ενεργοποιεί και διαγράφει λογαριασμούς ασκούμενων.
- Κάνει επαναφορά κωδικού. Ο προσωρινός κωδικός εμφανίζεται μία φορά και πρέπει να παραδοθεί στον ασκούμενο.

### Ασκούμενος

- Ο λογαριασμός του δημιουργείται από τον προπονητή· δεν υπάρχει δημόσια εγγραφή.
- Μετά την πρώτη σύνδεση αλλάζει τον προσωρινό κωδικό.
- Βλέπει τις ελεύθερες ώρες και μόνο τα δικά του ραντεβού.
- Μπορεί να κλείσει, να αλλάξει ώρα ή να ακυρώσει δικό του ραντεβού.
- Μπορεί να ζητήσει πρόταση από τον AI βοηθό και να την επιβεβαιώσει με ξεχωριστό κλικ.

Οι προστατευμένες σελίδες στο React βελτιώνουν την εμπειρία χρήσης, αλλά δεν αποτελούν μέτρο ασφάλειας. Τα middleware του Express ελέγχουν ξανά session, ενεργό λογαριασμό, ρόλο και δικαίωμα πρόσβασης σε κάθε σχετικό endpoint.

## Βάση δεδομένων

- `users`: username, bcrypt hash κωδικού, ρόλος, κατάσταση λογαριασμού και ένδειξη υποχρεωτικής αλλαγής κωδικού.
- `slots`: διαθέσιμες ημερομηνίες και ώρες.
- `appointments`: σύνδεση κράτησης με ώρα και ασκούμενο. Η `slot_id` είναι `UNIQUE`, άρα μία ώρα δεν μπορεί να έχει δύο κρατήσεις. Τα παλιά ραντεβού μπορούν να διατηρηθούν χωρίς λογαριασμό.
- `sessions`: συνεδρίες με λήξη, αποθηκευμένες στον server.
- `schema_migrations`: καταγραφή μεταφορών δεδομένων που εκτελούνται μία φορά.

Η SQLite βάση δημιουργείται στο `server/data/training-booking.sqlite`. Η παλιά λίστα ωρών από το `server/data/slots.json` εισάγεται μία φορά κατά την αρχικοποίηση της βάσης.

## Συνεδρίες και ασφάλεια

Το αναγνωριστικό συνεδρίας αποθηκεύεται σε cookie `httpOnly`, όχι σε `localStorage`. Έτσι ο client-side JavaScript δεν μπορεί να διαβάσει απευθείας το token της συνεδρίας. Σε παραγωγή, το cookie χρησιμοποιεί επίσης `Secure` και αποστέλλεται μόνο μέσω HTTPS.

Οι διαδρομές σύνδεσης έχουν rate limit και ουδέτερα μηνύματα σφάλματος. Η απενεργοποίηση λογαριασμού και η επαναφορά κωδικού ανακαλούν τις ενεργές συνεδρίες του ασκούμενου. Η βάση και οι συνεδρίες δεν εκτίθενται στον browser.

Η κράτηση εκτελείται μέσα σε SQLite transaction και η μοναδικότητα της `slot_id` επιβάλλεται επιπλέον από τη βάση. Έτσι δύο ταυτόχρονες αιτήσεις δεν μπορούν να κλείσουν επιτυχώς την ίδια ώρα.

## AI βοηθός

Ο βοηθός είναι **απενεργοποιημένος από προεπιλογή**: δεν εμφανίζεται στην πλοήγηση, ο server δεν αρχικοποιεί τον Anthropic client και το endpoint απαντά `503`. Έτσι η εφαρμογή λειτουργεί χωρίς API key και δεν στέλνει χρεώσιμα αιτήματα.

Η υλοποίηση παραμένει διαθέσιμη για μελλοντική δοκιμή. Μόνο αν θέλεις συνειδητά να την ενεργοποιήσεις, βάλε `AI_ASSISTANT_ENABLED=true` και ένα έγκυρο `ANTHROPIC_API_KEY` στο `server/.env` και επανεκκίνησε τον server. Η χρήση του API μπορεί να επιφέρει χρέωση. Ο βοηθός προτείνει μόνο· ο server ελέγχει το `slotId` και η κράτηση γίνεται μετά από επιβεβαίωση.

## Έλεγχοι

Από τον φάκελο `server`:

```powershell
npm.cmd test

```

Από τον φάκελο `client`:

```powershell
npm.cmd run lint

```

Τα integration tests ελέγχουν ότι:

- οι μη συνδεδεμένοι χρήστες δεν έχουν πρόσβαση στα endpoints του προπονητή,
- οι ασκούμενοι λαμβάνουν `403` στα trainer endpoints,
- ένας ασκούμενος δεν βλέπει, δεν αλλάζει ώρα και δεν ακυρώνει ραντεβού άλλου,
- δύο ταυτόχρονες κρατήσεις για την ίδια ώρα δεν μπορούν να πετύχουν και οι δύο.

Τα tests χρησιμοποιούν δική τους προσωρινή SQLite βάση και δεν αλλάζουν τα δεδομένα της εφαρμογής.
